## What you get from day one
- ### Model access
Open-weight and frontier models through one OpenAI- and Anthropic-compatible API.
- ### Server-side tools
Web search, web fetch and code execution for any model, open-weight included.
- ### API keys and budgets
A key for every person, team or agent, and spend caps that stop requests at the limit.
- ### Activity view
Every request with its tokens, cost and errors. Filter to find where an agent failed.
- ### Usage and cost
Cost, tokens and requests by model, person or API key, down to the hour.
- ### Fallback
Automatic fallback between providers.
