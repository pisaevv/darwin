1. Otari is an open-source AI gateway built by Mozilla AI, part of the Mozilla family.
2. Otari gives coding agents and applications access to open-weight and frontier models behind one API key.
3. Otari provides one OpenAI- and Anthropic-compatible endpoint, with the self-hosted gateway routing to 40+ providers.
4. Mozilla AI runs the hosted service on otari.ai, while the self-hosted option runs on your own infrastructure.
5. For companies, Mozilla AI offers either deployment model with deployment, support and the features the team needs.
6. Self-hosted Otari is free and open source, but you run it and pay for your own infrastructure.
7. Under early access pricing, hosted Otari has a 4.5% fee on top-ups and charges list price per token after top-up.
8. Your own provider keys are free with hosted Otari.
9. Otari's subscriptions for coding work have early access prices, include usage, charge no top-up fee and build in tools and guardrails.
10. Otari is licensed under Apache 2.0.
11. Otari supports a key for every person, team or agent and spend caps that stop requests at the limit.
12. Otari's revocable API keys can have user, workspace and model scope.
13. The Activity view shows every request's tokens, cost and errors and can be filtered to find where an agent failed.
14. Usage and cost reporting breaks down cost, tokens and requests by model, person or API key, down to the hour.
15. Otari provides automatic fallback between providers.
16. Local routing policies support failover, conditional selection, traffic splitting and spill-over past a rate limit.
17. Server-side tools provide web search, web fetch and code execution for any model, including open-weight models.
18. The open-source gateway's optional features include code execution, web search, MCP, inference guardrails and file understanding.
19. Provider credentials stay behind the gateway.
20. Otari authenticates requests, resolves provider credentials, enforces budgets before dispatch and records usage afterwards.
21. The providers listed as working with Otari today are Mistral, Fireworks AI, Together AI, Nebius, OVHcloud, Amazon Bedrock and DeepInfra.
22. The coding agents listed as working with Otari today are Claude Code, Codex, opencode, Junie and Pi.
23. Otari's listed SDK integrations are Otari SDK, OpenAI-compatible clients and any-llm.
24. Self-hosted Otari runs with your own database and provider keys.
25. Hosted setup starts with a free account using GitHub, Google or email, followed by creating an API key.
26. Pointing an agent at Otari requires setting its base URL, API key and model, after which every request appears in Activity.
27. The no-configuration Docker quickstart is `docker run -v otari:/data -p 127.0.0.1:8000:8000 mzdotai/otari:latest`.
28. On first start, Otari prints a setup link only once, and the link carries the master key and must be kept private.
29. Opening Otari's setup link lets you choose the email and password used to sign in.
30. The remaining quickstart steps are adding a provider on the dashboard's Hosted providers page, enabling default pricing and creating an API key.
31. OpenAI clients work by setting `base_url` to `http://localhost:8000/api/v1`.
32. The `otari` volume holds the SQLite database and a generated key that encrypts stored provider credentials.
33. Starting a new container with the same `-v otari:/data` preserves its data, while omitting `-v` gives each container a fresh anonymous volume.
34. The full-stack setup copies `config.example.yml` to `config.yml` and requires a master key, provider credentials and pricing there.
35. After `docker compose pull`, `docker compose up -d` runs Otari with PostgreSQL.
36. Optional Compose profiles `code-exec` and `web-search` add the code sandbox and web search services.
37. On PostgreSQL, storing provider keys through the dashboard requires setting `OTARI_SECRET_KEY` to a Fernet key generated by `otari gen-secret-key`.
38. In the Compose setup, provider copies of attached files are off until they have a pepper of their own.
39. Mozilla AI's company consultation includes a 30-minute call, an AI-spend assessment and a pilot proposal if Otari is a fit.
40. Otari help and support are available through Docs, Discord and GitHub issues.
